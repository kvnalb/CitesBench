# Pairwise Review Pipeline

This workstream handles pairwise ranking experiments.

Contents:

- pair scheduling (`all`, `random`, `swiss`, `anchor`)
- swap-order debiasing
- uncertain-pair re-ask logic
- file-backed pairwise prompts and persona definitions under `prompts/`
- persona-specific or committee-style pairwise judging
- ranking / evaluation utilities
- model-sweep summarization

This directory is intended to evolve independently from the paper-level review pipeline.
